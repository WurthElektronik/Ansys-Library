`Ansys Libraries for Würth Elektronik Products`
=========
## Introduction
Welcome to Würth Elektronik Ansys Library repository. <br>
The libraries are created and maintained by Würth Elektronik, for any questions and suggestions please feel free to contact us by email: <libraries@we-online.com>

## Library Component Coverage
* RF Antennas <br>
_WE-MCA_

* RF Inductors <br>
_WE-ACHC, WE-CAIR, WE-KI, WE-KIHC, WE-MK, WE-TCI_

* Filter Chokes <br>
_WE-SD_

* EMC Shielding <br>
_WE-SHC, WE-SHC_Seamless, WE-FAS_RFID, WE-FAS_EMI, WE-FSFS_

* Heatsinks <br>
_WE-HTOI, WE-HTO, WE-HICI, WE-HIC_

* RF Capacitors <br>
_WCAP-CSRF_

* SMA Connectors <br>
_WR-SMA Solderless, WR-SMA End Launch, WR-SMA Panel Flange, WR-SMA THT-THR-SMT_

* Thermal Management <br>
_WE-PCM, WE-TGS, WE-TGFG, WE-TGF, WE-TINS, WE-TTT_
